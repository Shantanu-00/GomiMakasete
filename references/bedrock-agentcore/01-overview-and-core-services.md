# Amazon Bedrock AgentCore: Overview & Core Services

> **Source**: AWS Official Documentation (`docs.aws.amazon.com/bedrock-agentcore`)

---

## 1. What is Amazon Bedrock AgentCore?

Amazon Bedrock AgentCore is an enterprise-grade agentic platform for building, deploying, and operating autonomous AI agents securely at scale. 

Instead of forcing developers to choose between open-source agility and enterprise infrastructure reliability, AgentCore provides a modular suite of cloud services that work with **any agent framework** (Strands Agents, LangGraph, CrewAI, LlamaIndex, Google ADK, OpenAI Agents SDK) and **any foundation model** (Bedrock Claude/Nova/Llama/Mistral, OpenAI GPT-4, Google Gemini).

## 2. Core Modular Services

| Service | Primary Purpose | Key Features | Supported Integrations |
| :--- | :--- | :--- | :--- |
| **AgentCore Runtime** | Purpose-built serverless hosting for code-based agents and tools. | Ultra-fast cold starts, true session isolation in microVMs, extended async execution, ARM64 architecture, HTTP/MCP/A2A contracts. | Strands, LangGraph, CrewAI, LlamaIndex, Google ADK, custom FastAPI/Express apps. |
| **AgentCore Harness** | Fully managed, zero-code orchestration agent loop. | Define model, system prompt, tools, and memory in JSON. AgentCore runs the loop inside an isolated microVM with local filesystem and shell. | Bedrock models, OpenAI, Gemini, LiteLLM. Integrated with Memory, Gateway, Code Interpreter. |
| **AgentCore Memory** | Context retention & persistent learning across conversations. | Short-term conversation history (sessions & events) + Long-term persistent knowledge extraction (Semantic, User Preference, Summary, Episodic). | Strands, LangGraph, LangChain, LlamaIndex. |
| **AgentCore Gateway** | Converts internal APIs and Lambda functions into MCP tools. | Instant Model Context Protocol (MCP) conversion, centralized endpoint routing, enterprise governance and permissions. | Lambda, OpenAPI, Salesforce, Slack, Jira, Zoom. |
| **AgentCore Identity** | Agent authentication and user authorization. | Inbound Auth & Outbound Auth, token exchange, enterprise IdP integration without user migration. | Amazon Cognito, Okta, Microsoft Entra ID, Auth0. |
| **Code Interpreter** | Sandboxed execution of code generated by models. | Secure isolated execution environment for Python code, data analysis, and mathematical computations. | Built-in tool for Harness and Runtime. |
| **AgentCore Observability** | Traces, metrics, and quality telemetry. | OpenTelemetry native, CloudWatch Application Signals, X-Ray transaction search, token accounting. | ADOT, CloudWatch, X-Ray. |

## 3. Two Development Approaches on AgentCore

When using AgentCore with the `@aws/agentcore` CLI or AWS console, you choose between two execution approaches:

### Approach A: Managed Harness (Configuration-Driven)
- **You provide**: A JSON/YAML declaration defining the model ID, system prompt, tool endpoints (MCP/Gateway), and memory configuration.
- **AgentCore provides**: The entire ReAct reasoning loop, tool execution engine, session microVM, and prompt stitching.
- **Best for**: Rapid prototyping, chatbots, standard tool-calling workflows without bespoke graph loops.

### Approach B: Custom Code Agent on Runtime (Code-Driven)
- **You provide**: Custom Python (Strands, LangGraph) or TypeScript code implementing your agent logic, packaged as a zip or container.
- **AgentCore provides**: High-density serverless microVM compute, auto-scaling, request routing, session sticky lifecycle management, and built-in IAM auth.
- **Best for**: Hackathon projects requiring custom heuristics, Strands supervisor/swarm topologies, specialized local tools, and custom streaming pipelines.
